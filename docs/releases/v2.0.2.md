# GZIST NetKeeper v2.0.2

## 下载

- **下载站：<https://dl2.nerv-base.com/>**（R2 + EdgeOne，无需访问 GitHub API 获取文件列表）
- GitHub 备用：<https://github.com/xiaomai1011/GZIST-NetKeeper/releases/tag/v2.0.2>
- Windows 常规电脑选 `windows-x64-setup.exe`；Apple M 系列选 `macos-arm64.dmg`；Linux 请选择对应架构的 deb 或归档。

## 登录与自动保活

- 保留 ACSetting 返回的错误提示；旧接口返回 HTML「系统发生错误」时明确显示原因，不再仅显示笼统的「登录失败」。
- HTML、空响应、异常 HTTP 状态或未知结果不再让旧接口提前放弃其余候选；严格识别 JSON/JSONP 成功码，兼容正常的空白和字符串/数字字段。
- 合入认证响应分类、认证服务器快速可达性检查和成功参数缓存。明确账号拒绝时停止无意义重试；服务器已确认成功但外网尚未放通时等待生效。
- 网络错误日志不再直接输出携带认证密码的请求 URL；新增一键复制脱敏日志，分享前仍请检查内容。
- 合入设置原子写入、账号切换凭据处理及跨平台日志轮转修复。

## 下载与自动更新

- **从 v2.0.2 起，新构建使用 `https://dl2.nerv-base.com` 检查和下载更新**，保留原有更新签名公钥。
- v2.0.1 及更早的客户端仍内置 GitHub 更新地址：可通过 GitHub 获得本次过渡更新，或从下载站手动安装 v2.0.2。仅换下载渠道不会改变旧安装包内置的源。
- 发布流水线核验六平台资产和更新签名；先上传并从公网校验版本化包，再发布更新清单。拒绝同名包覆盖、旧版本回退及已公开版本重跑。
- Linux deb/包管理器安装请通过包管理器或手动下载安装升级，不保证内置更新通知。归档安装可下载脚本和匹配架构的归档，核对来源与校验和后离线执行。

## 说明与限制

- 本次修复的是已复现的客户端错误处理和回退缺陷，**不等于已确定或修复学校认证服务器拒绝请求的原因**。仍需校内用户在同一设备、同一网络上测试。
- 认证失败请提供「复制脱敏日志」结果，并对照官方网页登录；不要公开密码、Cookie、token 或未脱敏 HAR。
- 安装包仍未购买商业代码签名证书，首次启动的系统安全提示可能继续出现。MyGo 更新归档的签名验证与普通安装器签名是两件事。
- 下载站不承诺校园网速度或 SLA；免费 EdgeOne 的用途限制、R2 请求/存储费用及源站安全边界见 [维护说明](https://github.com/xiaomai1011/GZIST-NetKeeper/blob/main/docs/release-mirror.md)。
