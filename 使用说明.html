广州理工学院 · 校园网自动登录工具

支持 WiFi / 有线 · 开机自启 · 休眠唤醒自动重连 · 零依赖（无需安装任何软件）

一、这个工具解决什么问题

学校的认证服务器（10.0.10.252）在电脑重启、休眠唤醒、WiFi 重连后会删除登录会话，所以每次都要重新打开网页输账号密码。这个工具会在后台默默检查网络：一旦发现掉线，就自动向认证服务器发送登录请求，全程无需你操作。

原理：参考了广州理工学院同学开源的登录脚本（GitHub: GZIST_CampusNet_AutoLogin），调用学校认证系统的 eportal 接口（http://10.0.10.252:801/eportal/），自动检测本机 IP 和 MAC 地址并携带账号密码完成认证。

二、快速上手（只需 3 步）

1
配置账号

双击 重新配置账号.bat，输入学号和校园网密码（输密码时屏幕上不显示，正常输入后回车即可）。

2
测试登录

先手动注销校园网（浏览器打开 10.0.10.252 点注销），再双击 校园网登录.bat。看到绿色的「登录成功」就说明配置正确。

3
安装开机自启

双击 安装开机自启.bat。之后每次登录 Windows 会自动在后台启动保活守护，重启、休眠唤醒后掉线也会在约 1 分钟内自动重连。装完无需重启，立刻生效。

建议：把这个文件夹放在桌面或其他固定位置，不要放进「下载」后随手删掉——开机自启会引用这里的脚本路径。
已实测：2026-09-11 在有线网环境完成了完整闭环测试（接口注销下线 → 自动检测掉线 → 自动重登 → 恢复上网），全程约 20 秒，结果见文件夹内《断网重连测试结果.txt》。检测改用 HTTPS 证书校验，校园网未认证时的 HTTP 劫持/白名单放行都不会再造成误判。

三、文件说明

文件作用
校园网登录.bat手动登录一次（带窗口，能看结果），测试用
重新配置账号.bat首次使用 / 改密码时运行，重新填写学号密码
安装开机自启.bat设置开机自动后台保活（注册表方式，无需管理员权限），并立即启动守护，推荐
启动后台保活.bat临时手动启动一次后台守护（已运行时会自动跳过，不会重复启动）
卸载开机自启.bat取消开机自启（同时清理旧版计划任务）
诊断检测.bat一键诊断：在线状态、门户劫持探测、网卡信息、配置文件
注销测试.bat一键注销校园网（调认证服务器接口），用来测试自动重连
campus_net.ps1核心脚本（自动改密码不用动它）
campusnet_log.txt运行日志（自动生成，出问题先看它）
campusnet_config.json保存你的账号密码（自动生成）

四、常见问题

现象解决办法
登录失败 ret_code=8先在手机或其他设备上打开 10.0.10.252 点「注销」把本机下线；再按 Win+R 输入 cmd，依次执行 ipconfig /release 和 ipconfig /renew，然后重新运行登录
登录失败 ret_code=2账号在别处登录了，先把其他设备下线
提示未检测到网卡先插网线或连上校园网 WiFi，再运行脚本
改了校园网密码双击 重新配置账号.bat 重新填一次
休眠唤醒后过了一会儿才恢复正常现象，守护每 60 秒检测一次，最多等约 1 分钟
想确认后台在不在运行打开 campusnet_log.txt 看最新记录；或任务管理器里搜 powershell

五、安全须知

  • 密码保存在本机 campusnet_config.json 里（仅做了编码混淆，不是强加密）。分享本工具给别人时，不要把自己的 campusnet_config.json 和 campusnet_log.txt 一起发出去（正式分享版压缩包已自动排除这两个文件）。
  • 脚本只向你学校的认证服务器发送登录请求，不上传任何数据到其他地方。
  • 仅供个人学习使用，请遵守学校网络使用规定；如学校更换认证系统，脚本需要更新。
