## 已在线时只保活，不重复登录

- 启动、保存账号、手动点击「立即登录」时，先判断当前外网是否可直连。确认在线就只进行周期性在线监测，不向认证服务器重复提交账号密码。
- 手动登录的在线判断前移到凭据检查之前：没有保存账号也能保持在线监测；实际掉线后的自动恢复仍需要有效账号密码。
- 恢复联网后清除残留的登录失败提示、错误码和重试计数。检测到「已经在线」不再改写上次实际登录时间。
- 保留原有掉线重连、失败退避、自动保活开关，以及手动注销和服务器明确拒绝后的暂停逻辑。

## HTTPS 在线探测兼容性

- 仅在收到特定的远端 TLS `handshake_failure` 告警时，尝试证书校验仍开启的 TLS 1.2 兼容探测；两次尝试共用原来的超时预算。
- 不忽略证书错误，不修改认证请求的传输方式，不将明文 HTTP 或跨站重定向当作可信的在线证据。
- 回归测试使用本地服务人为模拟握手不兼容，验证兼容探测成功后不提交登录，并验证不受信任的证书仍会被拒绝。**这不是对校内现场故障根因的确认，也不保证所有 TLS 握手失败都能因此解决。**

## 代理与认证状态的边界

- 在线探测仍采用直连，不读取系统代理或 `HTTP_PROXY` / `HTTPS_PROXY`。**仅浏览器通过代理可以上网、直连不通的情况，本版没有新增支持，仍可能触发登录尝试。**
- VPN/TUN 可以接管系统路由，程序禁用 HTTP 代理并不能绕过 TUN。
- 本版判断的是外网连通性，不是查询学校后台的账号会话，也不会把代理可用视为校园网已经认证。
- Windows 校内实际运行仍需用户验证。反馈时请使用「复制脱敏日志」，不要公开密码、Cookie 或 token。
