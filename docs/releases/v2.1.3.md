# v2.1.3 — 校园网 AC 发现修复

## 修复内容

- 正确解码认证页 URL 中的百分号编码参数（例如 `wlanacip=10%2E128%2E255%2E144`），并校验完整 IPv4 / MAC 地址，避免将 AC 错误截断为 `10`。
- 动态发现支持 Portal 根页最终重定向 URL、页面内认证链接，以及 AC 变量常见的引号和空白写法。
- 当前网关重定向提供的有效 AC 优先，其次为根页发现结果，最后为默认候选；避免旧会话参数抢在当前发现结果之前。
- 发现结果仅用于本轮登录，不修改共享候选列表，避免跨轮登录或客户端之间相互影响。
- 增加 AC `10.128.255.144` 作为兜底，不按用户 IP 网段硬编码映射。
- 保留纯 HTTP 协议、凭据存储、GB18030 响应解码和原有保活功能。

## 平台与更新

继续支持 Windows、macOS、Linux 的 amd64 / arm64，共六个目标。安装包和签名自动更新包由 GitHub Actions 构建；发布流程校验完整资产及公开更新源后才公开 Release。

## 验证边界

回归测试通过本地模拟网关验证编码参数、AC 优先级、首个认证请求及跨轮状态隔离，测试使用合成终端地址，不使用真实用户账号，也不访问学校认证接口。未进行真实校园网登录验证；实际联网效果仍需升级后在对应网络环境确认。
